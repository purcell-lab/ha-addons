# CitrineOS Operator UI App

Home Assistant App for the [CitrineOS](https://citrineos.github.io/) v2.1.0
Operator UI, served through Ingress for the isolated CitrineOS lab:
read-only data and an optional, bounded set of OCPP commands through the lab
server's gateway. Prebuilt for amd64 and aarch64. See `DOCS.md`.
